# HERMES-by-team-KRONEFIA
HERMES is a real-time fraud defense engine for digital lenders. It spots coordinated fraud rings, mule wallets and VPN-masked accounts using fast vector search, graph analysis and a self-learning neural network, while approving genuine festive-season borrowers. Built with FastAPI, NumPy, scikit-learn and NetworkX, it handles ~394 requests/sec.
